# PostgreSQL Expense Analysis E2E Fixture

This fixture is the second-stage local execution substitute for validating the
SQL Server read-only SELECT subset generated by `skill_scripts.sql_generator`.
The first stage is the local SQLite E2E, which runs before this PostgreSQL
fixture. PostgreSQL is used here as the local simulation of the formal MSSQL DB
execution target.

## Contract

- Service/container: `wferp-postgres-e2e`
- Database: `wferp_e2e`
- User: `wferp`
- Password: `wferp_pass`
- Host port: `55432`

The fixture creates schema `dbo` and quoted uppercase tables `ACPTA` and
`ACPTB`, then seeds deterministic expense voucher data for 2026 Q1 plus
excluded control rows for date, confirmation, and void filters.

Run the full E2E path from the repository root:

```bash
bash scripts/run_expense_analysis_postgres_e2e.sh
```

The runner executes `bash scripts/run_expense_analysis_sqlite_e2e.sh` first,
then starts and validates this PostgreSQL fixture.
