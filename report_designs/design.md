# Design Contract

Each report design must define the following front matter keys:

- `id`
- `name`
- `best_for`
- `required_sections`
- `optional_sections`
- `visual_policy`
- `table_policy`
- `analysis_policy`
- `recommendation_policy`
- `react_component_hints`
- `validator_checklist`

The content after front matter should explain how the report should be structured, what evidence is expected, and which validator concerns are most important.
