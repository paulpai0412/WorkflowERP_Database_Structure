# Scaffold

Use `assets/scaffold-template/` as a lightweight starting point for report rendering.

Expected flow:
1. Copy scaffold files into the run folder when a React-based report is useful.
2. Replace placeholder payload with generated report payload JSON.
3. Render charts, metrics, tables, and evidence from local data.
4. Export a single HTML file for delivery.

Keep scaffold text clean UTF-8 and avoid environment-specific secrets.
